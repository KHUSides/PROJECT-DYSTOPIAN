## 0. 담당 범위 정리

### 내가 담당하지 않는 것

- 플레이어 구현
- 리듬 노트 시스템 구현
- 적 AI 및 적 공격 구현
- 보스 패턴 구현
- NPC 구현

### 내가 담당하는 것

- 레벨 구현
- UI 구현
- 게임 진행 시스템 중 레벨/UI와 직접 연결되는 부분

즉, 플레이어·리듬·적·보스·NPC 자체를 만들지는 않지만, 그 시스템들이 들어올 수 있도록 **스테이지 구조, 진행 흐름, UI 표시 위치, 전투 구간 트리거, 결과 화면**을 준비하는 것이 핵심이다.

## 1. 먼저 정해야 할 연동 기준

구현 전에 다른 담당자와 인터페이스를 맞춰야 한다.

### 1-1. 리듬 시스템 연동 기준

내가 직접 구현하지 않지만, 레벨과 UI가 리듬 시스템을 호출하거나 표시해야 하므로 다음 정보가 필요하다.

- 스테이지별 BMS 또는 음악 데이터가 어디에 배치되는지
- 전투 시작 시 리듬 시스템을 시작하는 호출 방식
- 전투 종료 시 리듬 시스템을 멈추는 호출 방식
- 노트 UI가 리듬 시스템에서 직접 그려지는지, 내가 만든 UI 영역에 붙는지
- 판정 결과, 콤보, ATTACK 상태 같은 정보가 UI로 전달되는 방식

내 작업:

- [x] 스테이지 시작/종료 지점에 리듬 시스템 호출 위치를 마련한다.
- [x] UI에 노트 라인, 판정, 콤보 등을 표시할 공간을 준비한다.
- 실제 노트 생성과 판정 로직은 리듬 시스템 담당자에게 맡긴다.

### 1-2. 플레이어 시스템 연동 기준

내가 직접 구현하지 않지만, 레벨 진행과 카메라/트리거가 플레이어 위치를 기준으로 동작해야 한다.

필요 정보:

- 플레이어 오브젝트 참조 방식
- 플레이어 조작 잠금/해제 호출 방식
- 플레이어 위치 이동 또는 텔레포트 호출 방식
- 플레이어 어둠 지수, 골드, 영혼, 피해량, 콤보 값을 UI에서 읽는 방식

내 작업:

- 자동 진행 구간에서 조작 잠금 요청 지점을 만든다.
- 스테이지 이동, 텔레포트, 시작 위치 배치 지점을 만든다.
- UI가 플레이어 상태를 표시할 슬롯을 만든다.

### 1-3. 적/보스 시스템 연동 기준

내가 직접 구현하지 않지만, 레벨에는 적과 보스가 배치되어야 한다.

필요 정보:

- 적/보스 프리팹 이름과 배치 방식
- 스폰 지점 또는 씬 배치 방식
- 적 수 변경 이벤트
- 보스 체력/이름/공격 스택 UI 전달 방식
- 보스전 시작/종료 이벤트

내 작업:

- 적 배치 위치, 스폰 포인트, 전투 방벽을 만든다.
- 보스전 공간, 보스 등장 지점, 퇴로 차단 지점을 만든다.
- 남은 적 수, 보스 체력 등 UI 표시 공간을 만든다.
- 적/보스의 실제 행동과 패턴은 담당자에게 맡긴다.

### 1-4. NPC 시스템 연동 기준

NPC 자체는 담당하지 않는다.

내 작업:

- NPC가 배치될 위치를 레벨에 마련한다.
- NPC 대화가 필요한 구간을 문서화한다.
- NPC 대화 UI가 들어갈 화면 영역을 준비한다.
- NPC 상호작용 로직과 대사 진행은 NPC 담당자에게 맡긴다.

## 2. 게임 진행 시스템

플레이어/리듬/적/보스 자체 구현은 제외하고, 스테이지와 UI를 이어주는 진행 흐름만 담당한다.

### 2-1. 스테이지 상태 관리

구현 목표:

- 현재 게임이 어느 구간에 있는지 관리한다.
- 스테이지 입장, 전투 시작, 전투 종료, 다음 구간 해금 흐름을 제어한다.

필요 상태:

- Tutorial
- Lobby
- NormalStage
- BossStage
- Branch
- Ending
- Result
- ChallengeMode

필요 기능:

- [~] 스테이지 시작 이벤트
- [x] 서브 스테이지 시작 이벤트
- [x] 서브 스테이지 클리어 이벤트
- 보스 스테이지 시작 이벤트
- 보스 스테이지 종료 이벤트
- 다음 구간 해금
- 문 열림/길 막힘/텔레포트 같은 레벨 이벤트 실행

### 2-2. 서브 스테이지 진행

구현 목표:

- 일반 스테이지는 여러 전투 구간으로 나누어 진행한다.
- 전투 구간에 들어가면 방벽이 닫히고, 클리어 전에는 나갈 수 없게 한다.

필요 기능:

- [x] 서브 스테이지 진입 트리거
- [x] 전투 시작 요청
- [x] 방벽 활성화
- [x] 남은 적 수 UI 갱신 요청
- [x] 클리어 시 방벽 해제
- 음악 볼륨 변화 또는 다음 구간 전환 요청

주의:

- 적 처치와 적 AI는 담당하지 않는다.
- 남은 적 수는 적 시스템에서 전달받아 표시한다.

### 2-3. 보스 스테이지 진행

구현 목표:

- 보스전 시작 전 연출, 보스 등장, 후퇴 차단, 보스전 종료 후 길 열림을 관리한다.

필요 기능:

- 보스 구역 진입 트리거
- 자동 진행 또는 컷씬 시작 요청
- 보스 등장 위치
- 보스전 시작 요청
- 후퇴 경로 차단
- 보스 HUD 표시 요청
- 보스전 종료 시 다음 길 개방

주의:

- 보스 패턴은 담당하지 않는다.
- 보스 체력, 공격 스택, 패턴 진행은 보스 담당 시스템에서 처리한다.

### 2-4. 분기와 엔딩 진행

구현 목표:

- 중간 보스 이후 스테이지 1로 복귀하고, 가짜 엔딩과 진짜 루트로 갈라지는 흐름을 만든다.

필요 기능:

- 중간 보스 종료 후 스테이지 1 복귀
- 복귀 후 자동 진행 구간
- 왕궁 밖으로 나가면 가짜 엔딩
- 이전 보스전 공간으로 이동하면 스테이지 5 루트 진입
- 최종 보스 종료 후 진짜 엔딩
- 엔딩 후 결과/기록 화면 연결

## 3. UI 구현

UI는 실제 시스템 로직을 만들기보다, 다른 시스템에서 전달받은 값을 표시하고 플레이어가 선택할 수 있는 화면을 만드는 역할이다.

### 3-1. 전투 HUD

구현 목표:

- 전투 중 필요한 정보를 표시한다.

필요 UI:

- [x] 노트 라인 표시 영역
- [x] 판정선 표시 영역
- [x] 판정 텍스트 표시 영역
- [x] 콤보 표시
- 플레이어 어둠 지수 표시
- 잠식된 영혼 표시
- 현재 강화 상태 표시
- [x] 서브 스테이지 남은 적 수 표시
- 보스 이름/체력 표시
- 보스 공격 스택 표시

주의:

- 노트 생성과 판정 계산은 담당하지 않는다.
- UI는 리듬 시스템/플레이어 시스템/적·보스 시스템에서 전달받은 값을 표시한다.

### 3-2. 스테이지 안내 UI

구현 목표:

- 현재 목표와 진행 상태를 알려준다.

필요 UI:

- 현재 스테이지 이름
- 현재 서브 스테이지 진행 표시
- [x] 전투 시작 카운트다운 표시 영역
- 클리어 표시
- 다음 구간 안내
- 조작 잠금 중 안내 표시

### 3-3. 튜토리얼 안내 UI

구현 목표:

- 튜토리얼 구간에서 조작법과 목표를 안내한다.

필요 UI:

- 좌클릭 이동 안내
- 우클릭 점프 안내
- A 단일 노트 안내
- D 롱 노트 안내
- 연습 전투 목표 표시
- 튜토리얼 완료 안내

주의:

- NPC 대화 진행은 담당하지 않는다.
- NPC 대화가 필요한 위치와 화면 영역만 준비한다.

### 3-4. 로비 UI

구현 목표:

- 로비에서 전투 준비, 기록 확인, 장식품, 연습, 훈련에 접근할 수 있게 한다.

필요 UI:

- 전투 준비 메뉴
- 아이템 선택 메뉴
  - 콤보 방어막: 50골드
  - 스팀팩: 100골드
  - 족쇄: 0골드
  - 선택 안 함
- 전투 기록 메뉴
  - 최근 10회 플레이
  - 최고 점수
  - 최고 콤보
- 장식품 구매/착용 메뉴
- 연습 전투 재신청 메뉴
- 훈련 모드 진입 메뉴

주의:

- NPC 상호작용 로직은 담당하지 않는다.
- UI 메뉴와 화면 전환만 담당한다.

### 3-5. 강화 UI

구현 목표:

- 전투 중 또는 지정된 상황에서 영혼을 사용해 강화할 수 있는 화면을 제공한다.

필요 UI:

- 공격력 강화
- 어둠 저항 강화
- 웨이브 스워드
- 웨이브 임팩트
- 소리 방어막
- 현재 영혼 수
- 강화 비용
- 최대 강화 도달 표시

주의:

- 강화 효과 자체는 플레이어/전투 시스템 담당 영역이다.
- UI는 선택과 표시를 담당하고, 실제 적용은 담당 시스템에 요청한다.

### 3-6. 결과/등급 UI

구현 목표:

- 한 판 종료 후 진행도, 최대 콤보, 피해량, 등급, 골드 보상을 보여준다.

표시 항목:

- 진행도
- 최대 콤보
- 입은 피해량
- 등급
- 지급 골드
- 클리어 여부
- 가짜 엔딩 기록 표시: `클리어?`

등급 기준:

- U: 진행도 100%, 풀 콤보, 노 히트
- S: 진행도 100%, 최대 콤보 100 이상, 피해량 200 이하 중 2개 이상
- A: B 조건은 모두 달성, S 조건은 1개만 달성
- B: 진행도 70% 이상, 최대 콤보 50 이상, 피해량 400 이하 중 2개 이상
- C: D 조건은 모두 달성, B 조건은 1개만 달성
- D: 진행도 30% 이상, 최대 콤보 30 이상
- F: D 조건 미달

골드 보상:

- U: 700
- S: 100
- A: 90
- B: 80
- C: 60
- D: 40
- F: 10

## 4. 레벨 구현 공통 규칙

### 4-1. 맵 구조

구현 목표:

- 각 스테이지는 일반 서브 스테이지와 보스 구간으로 구성한다.
- 같은 스테이지의 서브 스테이지는 한 맵 안에서 진행한다.

규칙:

- 기본 구조는 일반 서브 스테이지 5개 + 보스 1개
- 서브 스테이지는 방벽으로 구분
- 클리어 전에는 해당 구간을 벗어날 수 없음
- 서브 스테이지 사이 콤보는 유지되지 않음
- 횡스크롤과 종스크롤은 모두 사용 가능
- 한 구간에서 X/Y 동시 스크롤은 사용하지 않음
- 카메라 크기를 가로/세로 모두 넘어가는 맵은 만들지 않음

### 4-2. 배치해야 할 공통 오브젝트

- 플레이어 시작 위치
- 카메라 경계
- 서브 스테이지 진입 트리거
- 전투 방벽
- 적 스폰/배치 위치
- 보스 등장 위치
- 보스전 퇴로 차단 오브젝트
- 다음 구간 문 또는 이동 경로
- 파괴 가능한 작은 지형지물
- 골드 지급 지형지물
- 컷씬/자동 진행 트리거
- NPC 배치 위치

주의:

- 적/보스/NPC의 실제 동작은 담당하지 않는다.
- 레벨 안에 배치 위치와 트리거만 준비한다.

## 5. 레벨 구현 순서

### 5-1. 튜토리얼 - 신참 영웅

구현 내용:

- 최초 등장 위치
- 자동 진행 구간
- NPC 배치 위치
- 부패한 쥐 예시 공간
- 스피커 예시 오브젝트 위치
- 조작 연습 공간
