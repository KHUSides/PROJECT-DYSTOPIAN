# 코드 컨벤션

#### — 네이밍

- 기본은 camelCase 사용
    - 변수는 처음 소문자, 띄어쓰기 구분되는 첫문자는 대문자
    - 함수, 클래스는 처음부터 대문자
- 멤버 변수는 뒤에 ‘_’ 붙이기
- 인터페이스는 I로 시작하기
    - IDamegeSystem같이
- 코루틴은 뒤에 ‘Crtn’ 붙이기

#### — 생명 주기 함수

- 변수 초기화는 Awake에서
- 다른 객체 참조는 Start에서
- 사용자 입력 처리는 Update에서
- 물리 처리는 FixedUpdate에서
- 애니메이션 같이 업데이트 후 이뤄지는 것들은 LateUpdate에서
- 안쓰는 생명 주기 함수는 지워버리기

#### — 기타

- Destroy(), Instantiate() 웬만하면 지양하기
    - 대신 SetActive 혹은 enabled로 관리
    - 가끔가다 한번 호출되는거면 상관없음
- 주석은 꼭 필요한것만
- UI에 불필요한 애니메이터 금지
- API의 형태로 최대한 디커플링되도록
- 무분별한 싱글톤 지양하기

# 버전 관리

- 뭔가를 커밋하기 전에 풀 한번 받고 하기
- 다른 사람 씬이나 스크립트 만지기 전에 물어보고 하기

| [기능 추가] | 새로운 기능 작성 & 테스트 완료 |
| --- | --- |
| [기능 수정]  | 기존 기능의 로직 수정 & 테스트 완료 |
| [리팩토링] | 기존 코드를 리팩토링 |
| [에셋 추가] | 프로젝트에 에셋 파일을 추가 |
| [패키지 추가] | 프로젝트에 패키지 / 에셋  파일을 추가 |
| [파일 설정] | 파일(프리팹 포함)의 설정을 변경 |
| [오류 수정] | 오류를 수정해 더이상 발생하지 않음 |
