# Free Rhythm 테스트 버전

명세: [프로젝트 리뉴얼 기획안 — 리듬 시스템](https://app.notion.com/p/3cc7bdb21c488089b390d9a17a0fd926)
문서의 비트 스펠 레퍼런스에 따라, 노트 채보 없이 사용자가 입력한 리듬을 행동으로 변환합니다.

## 실행

- Unity 메뉴 `Dystopian > Free Rhythm > Open Test Scene` 또는 `Assets/DongJun/FreeRhythm/FreeRhythmTest.unity`를 열고 Play.
- 기존 `PlayerTest`, `RhythmTest`, `RhythmSystem`, 플레이어 스크립트 및 프리팹은 변경하지 않았습니다.
- 새 씬은 PlayerTest의 복사본입니다. 복사본에서 기존 리듬 오브젝트와 기존 판정 표시를 비활성화하고 새 시스템을 추가했습니다. 더미는 플레이어 오른쪽 가까이에 배치했습니다.
- 플레이어 체력 초기값 0은 원래대로 유지했습니다. 체력이 0이어도 기존처럼 공격을 테스트할 수 있습니다.

## 박자와 조작

- 컴포넌트 기본값은 120 BPM이며 현재 테스트 씬의 60 BPM 설정은 유지합니다. 4/4 고정, 8분음표 간격은 `30 / BPM`초이며 한 마디에 8개 타이밍이 있습니다.
- 한 마디 카운트인 후 `1 & 2 & 3 & 4 &`를 계속 반복합니다. DSP 시계와 예약 재생 메트로놈을 사용합니다.
- A와 D는 대등한 키입니다. 정박과 반박 모두 입력 가능하며, 마디를 넘어 조합을 이어갈 수 있습니다.
- 방향키 이동 / 위 방향키 점프, R 리듬 재시작, ESC 기존 일시정지 메뉴.
- 아무 입력도 하지 않으면 쉼입니다. 쉰 박자는 미스나 콤보 페널티를 만들지 않습니다.
- 기본 판정: Perfect ±35ms, Good ±90ms. 높은 BPM에서는 Good 범위를 간격의 45%로 제한합니다.
- 입력은 가장 가까운 8분음표 시점의 전후로 판정합니다. 정박 사이의 중간 지점은 입력 가능 구간이 아닙니다. 예: 120 BPM에서 0.25초 박자는 0.16~0.34초가 Good 이상입니다.
- Input System에 기록된 키 이벤트 시각을 DSP 시계로 변환하여 판정합니다. 대기 중인 키 이벤트를 처리한 후 지난 박자를 닫으므로 늦게 처리된 프레임이 입력 시각을 바꾸지 않습니다.
- 메트로놈과 인디케이터/입력 판정에는 오디오 출력 지연 보정을 함께 적용합니다. `Estimate Audio Latency From Dsp Buffer`는 현재 장치의 Unity DSP 버퍼로 기본 지연을 추정하고, `Audio Latency Adjustment Seconds`는 플레이어별 장치 지연을 더하거나 뺍니다. 자동 추정을 끄면 Adjustment 값이 전체 지연값이 됩니다.
- 공격 조합은 마지막 입력에서 즉시 시전됩니다. 입력하지 않은 타이밍의 쉼/홀드는 해당 판정 구간이 닫힌 뒤 확정합니다.
- 키를 누른 뒤 다음 8분음표의 조기 판정 구간 전에 놓으면 탭 해제로 처리합니다. 그 구간부터는 박자에 맞춘 홀드 해제로 판정합니다.
- 사각형 테두리의 `1 & 2 & 3 & 4 &`를 인디케이터가 시계 방향으로 순회합니다. 표시 통과 시각이 정박이며 초록 구간은 Perfect, 노란 구간은 Good입니다. 한 바퀴는 한 마디입니다.

## 임시 행동 조합

아래 각 칸은 8분음표 한 칸입니다. `입력`은 A 또는 D를 짧게 누르기, `쉼`은 누르고 있는 키도 없는 상태입니다. 같은 키로 반복하거나 두 키를 섞어도 됩니다.

| 행동 | 입력 조합 | 현재 연결 |
|---|---|---|
| 휘두르기 | 입력 → 쉼 → 입력 | 마지막 입력에서 일반 공격 |
| 2단 베기 | 입력 → 입력 → 입력 → 입력 | 세 번째와 네 번째 입력에서 각각 공격. 네 번째 입력을 생략하면 두 번째 공격도 생략 |
| 차징 공격 | 누르기 → 유지 → 유지 → 유지 → 놓기 | 2박 홀드 후 박자에 맞춘 해제로 기존 차징 돌진 |
| 가드 후 공격 | 누르기 → 다음 칸에 놓기 → 입력 | 반박 홀드 해제로 1회 피해 방어막, 후속 입력으로 일반 공격 |
| 같은 박자 중복 입력 | A+D 같은 칸 | 현재 프로토타입은 첫 누름만 수용 |
| 홀드 중 공격 | 한 키 유지 중 반대 키 입력 | 일반 공격 +5 피해 |

차징은 문서의 예시와 달리 선행 준비 탭을 생략한 테스트 조합입니다. ‘입력-쉼-입력’이 휘두르기와 중복되는 것을 피했습니다. 가드는 기존 SoundBarrier API를 활용하므로 공격 한 번을 막을 때까지 유지됩니다. 가드/동시 공격/홀드 중 공격의 전용 애니메이션은 아직 별도로 제작하지 않았습니다.

모든 관련 입력이 Perfect이면 추가 피해 +10이 적용됩니다. 반박도 Perfect 판정이면 인정합니다. 기본 공격 피해는 기존 플레이어 설정을 사용하며, 임시 피해 보너스는 시전 직후 복구합니다.

콤보는 플레이어의 `TargetDamaged` 이벤트에서 양수 피해가 보고될 때 증가합니다. 입력 성공만으로 증가하지 않으며, 허공 공격도 증가시키지 않습니다. 플레이어 체력 감소 또는 리듬 재시작 시 초기화됩니다.

## 조정과 확장

- 새 씬의 `Free Rhythm System (4-4)` → `FreeRhythmSystem`에서 BPM, 판정 폭, 입력 보정, 오디오 지연 보정, 키, 메트로놈 볼륨을 조절합니다. 플레이어 설정 메뉴에서는 `SetAutomaticAudioLatency`와 `SetAudioLatencyAdjustment` API로 즉시 변경할 수 있습니다. BPM/판정 폭을 Play 중 바꿨다면 R로 다시 시작합니다.
- 기본 사운드는 메트로놈입니다. 음악을 사용할 때는 일정한 BPM의 클립을 Music에 넣고 BPM을 맞추세요. 음악은 카운트인 뒤 첫 박자에 시작합니다. 무한 루프 연결도 같은 박자가 되도록 음악 길이와 시작점을 편집해야 합니다.
- `FreeRhythmEngine`: 타이밍/조합 판정. 현재 조합은 C#에 정의된 프로토타입 규칙입니다.
- `FreeRhythmSystem`: 입력 수집, 박자 시계, 메트로놈, 판정/행동 이벤트.
- `FreeRhythmPlayerBridge`: 기존 플레이어 API 및 피해 콤보 연결.
- `FreeRhythmHUD`: 사각형 테두리 박자표, 연속 인디케이터, 입력 기록, 판정, 행동, 콤보 표시. `Perimeter Center/Size`, 선·표시·인디케이터 크기, 색상 및 `Show Timing Windows`를 인스펙터에서 조절합니다. 좌표는 1280×720 기준으로 화면에 비례해 표시됩니다.
- 적 공격 예고와 스테이지별 BPM 전환, 음악 제작은 이번 별도 테스트 시스템에 포함하지 않았습니다.

## 검증

- `Dystopian > Free Rhythm > Run Timing Checks`: 정박 전후, 마디 경계, 60~300 BPM, 판정 경계, 사각형 좌표 및 기존 공격 조합 검사.
- `Dystopian > Free Rhythm > Run Immediate Input Checks (Play Mode)`: 입력·공격 즉시 반응, 탭 해제, 지연된 입력 이벤트, 중복 방지 및 기존 홀드 조합 검사. 테스트 후 리듬이 재시작됩니다.
- `Dystopian > Free Rhythm > Run Keyboard Timestamp Checks (Play Mode)`: Input System 가상 키보드의 실제 이벤트 경로로 정박 직전/정각/직후를 검사합니다. 기본 A 키 설정에서 실행합니다.
- 2026-09-09 개편 검증: 타이밍·조합·좌표 228개, 플레이 모드 입력 32개, 키보드 이벤트 3개 검사.
- Unity 컴파일과 플레이 모드 콘솔 및 사각형 박자표 화면을 확인합니다.
